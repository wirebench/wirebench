# Host seam (slice 1 of #776) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking.

**Goal:** The desktop main process becomes `@wirebench/host`, a factory `createHost(platform)` with no
Electron import and no module-level mutable state, embedded by the Electron app, with no user-visible change.

**Architecture:** Two parts, one pull request each. **Part A** draws the seam in place, inside
`apps/desktop/src/main`: a `HostPlatform` interface, a `Caller` in place of `WebContents`, every Electron call
behind the platform, the composition root rewritten as `createHost`, per-host state instead of module state,
and a gate that keeps it so. Electron stays only in `src/main/electron/` and `src/main/index.ts`. **Part B**
moves what Part A made Electron-free into `packages/host`, and the shared wire code it depends on into
`packages/wire`, with no behaviour change. Doing the seam before the move means every intermediate commit
builds and passes, and the move is mechanical.

**Tech Stack:** TypeScript (ESM), Electron + electron-vite, vitest, pnpm workspaces, the existing
`scripts/*` gate style.

**Spec:** `docs/specs/2026-10-24-wirebench-hosted-edition-design.md` §3.1, §5.1, §5.2, §10 row 1, §11;
`docs/adr/0033-one-host-package-serves-the-desktop-the-agent-and-the-server.md`; issue #777.

## Global Constraints

- No user-visible change: same channels, same files under `userData`, same `safeStorage` entries, same
  menus, same startup (the macOS window-usable guard of #623 still holds).
- The channel registry, zod schemas and the `IpcResult` envelope do not change shape
  (`apps/desktop/src/shared/ipc.ts`, `apps/desktop/test/fixtures/ipc-names.json` unchanged).
- `@wirebench/host` imports no `electron`; enforced by a gate in `pnpm check`, not by `eslint.config.js`
  (that file is hook-protected).
- No module-level mutable state in host code: no top-level `let`, and no top-level `new Map | Set |
  WeakMap | WeakSet` unless typed `ReadonlySet`/`ReadonlyMap` and never mutated.
- No socket transport, no agent, no browser build: those are slices 2 and 3.
- Commit after every task with `WIREBENCH_SKIP_PERF=1 pnpm check` green; `pnpm test:perf` before each push.
  `eslint .` needs `--ignore-pattern '.claude/worktrees/**' --ignore-pattern 'git-worktrees/**'` and
  `NODE_OPTIONS=--max-old-space-size=8192` locally or it aborts out of memory.
- After any change to main's bundling, run `pnpm --filter @wirebench/desktop build` too: `pnpm check` does
  not catch a truncated main bundle (the "import"-string trap).
- No local Electron e2e windows; CI runs e2e. Commits as Mohammed Naami, no trailers.

## Review Focus

1. **Two hosts in one process sharing a secret masker.** `redact.ts` keeps the recorded secret values in
   module state; a second host must not mask with, or leak, the first host's values. Test in Task 4.
2. **An event emitted to a closed window.** Today `emitEvent` returns early on `target.isDestroyed()`; a
   `Caller` must keep that, or a late progress event throws in main. Test in Task 2.
3. **A dialog with no owning window.** `BrowserWindow.fromWebContents(sender)` can return `null` (a sender
   gone mid-call); `platform.dialogs` must then open an unparented dialog, as Electron does today, not
   throw. Test in Task 3.
4. **A second `createHost` on the same process.** The factory must not re-run process-wide side effects
   (`app.setName`, protocol registration, single-instance lock); those stay in the Electron entry. Test in
   Task 5.
5. **The packaged app after the move.** `externalizeDepsPlugin` externalises workspace packages; if
   `@wirebench/host` or `@wirebench/wire` is externalised, the packaged app fails to start while dev
   works. Covered by `check-desktop-asar` plus a bundle test in Task 8.

  export type Capability = 'files' | 'keychain' | 'ssh' | 'pty' | 'kerberos' | 'dialogs' | 'send:private'
    | 'send:public' | 'secret-sources' | 'team-secrets' | 'updates' | 'app-lock';
  export interface Caller {
    readonly id: number;
    send(channel: string, payload: unknown): void; // no-op once closed
    isClosed(): boolean;
    onClosed(listener: () => void): () => void;
  }

  export interface SaveDialogOptions { /* the same, for showSaveDialog */ }
  export interface MessageBoxOptions { /* the same, for showMessageBox */ }
  export interface HostPlatform {
    readonly paths: { userData(): string; temp(): string; logs(): string };
    readonly secrets: { available(): boolean; encrypt(plain: string): Buffer; decrypt(sealed: Buffer): string };
    readonly dialogs?: {
      openFile(owner: Caller | undefined, opts: OpenDialogOptions): Promise<{ canceled: boolean; filePaths: string[] }>;
      saveFile(owner: Caller | undefined, opts: SaveDialogOptions): Promise<{ canceled: boolean; filePath?: string }>;
      message(owner: Caller | undefined, opts: MessageBoxOptions): Promise<{ response: number; checkboxChecked: boolean }>;
    };
    readonly shell?: { openExternal(url: string): Promise<void>; openPath(path: string): Promise<string>;
      reveal(path: string): void; trash(path: string): Promise<void> };
    readonly app: { version(): string; packaged(): boolean; quit(): void; osTheme(): 'dark' | 'light';
      onOsThemeChanged(listener: () => void): () => void };
    readonly proxy: { resolve(target: string): Promise<string> }; // Electron's PAC string, 'DIRECT' when none
    readonly power?: { onResume(listener: () => void): () => void };
    readonly capabilities: ReadonlySet<Capability>;
