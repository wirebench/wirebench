# Domains (slice 6 of #776) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for
> tracking.

**Goal:** The hosted names become settings, the wildcard certificate gets a tested deployment recipe, `app.<app-domain>`
mails a person the links of their teams, and no tenant can take a reserved slug. No domain is owned, so no real name
appears anywhere.

**Architecture:** Three parts, one pull request each, in dependency order.

- **Part A** (Tasks 1–4): the two names in the config, the reserved slugs, the apex and entry branches of the
  resolver.
- **Part B** (Tasks 5–8): the `entry` module: the page, the form, the rate limits, the queue, the per-tenant lookup and
  the mail.
- **Part C** (Tasks 9–11): the Traefik recipe and its test, the operator runbook with the public suffix step, the docs.

**Tech Stack:** TypeScript (ESM), Fastify 5 (host constraints), `pg`, `nodemailer` (already a dependency), Traefik v3
(lego's `hetzner` DNS-01 provider), vitest, `yaml` for the recipe test.

**Spec:** `docs/specs/2026-10-24-wirebench-hosted-edition-design.md` §3.2, §3.6, §3.7, §19.5 and §21 (which wins where
they differ); ADR-0038; issue #822.

## Global Constraints

- **No real domain.** Code, tests, docs and examples use `<app-domain>`, `<site-domain>`, `app.test`, `site.test` or
  `example-app.test`. A test greps the changed files for `wirebench.co` and the other names of decision 4.
- **Hosted mode stays refused** by `loadConfig` (§19.1). Tests build a hosted `ServerConfig` directly, as slice 4's do.
- **Self-hosted unchanged.** The two new variables are accepted and unused there; no page, route or output changes.
- **Out of slice 5's way.** Nothing in `live/`, the repo-store lock, the host lease or socket, budgets or metrics. Shared
  files (`config.ts`, the spec, `CHANGELOG.md`, the server README) get small, local edits.
- **Gates.** `WIREBENCH_SKIP_PERF=1 pnpm check` green before each task's commit; one commit per task, as Mohammed
  Naami <m.naami@outlook.com>, no trailers. `pnpm lint`, never bare `eslint .`. No local Electron or e2e windows.

## Review Focus

1. **The entry as an oracle.** Any difference between known, unknown, malformed and rate-limited inputs: status,
   body, headers, timing before the response. Tasks 6 and 7.
2. **The entry reaching a tenant it should not.** A route on `app.` that reads `request.tenant`, a lookup outside a
   tenant unit, the default tenant or a disabled user matching. Tasks 3 and 7.
3. **Mail content.** Tenant names as plain text, no token, no address in a log line. Task 7.
4. **The recipe.** Only Traefik publishes a port; apex and wildcard on one certificate; the token as a file secret.
   Task 9.
